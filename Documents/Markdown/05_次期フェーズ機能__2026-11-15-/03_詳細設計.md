# 詳細設計書：ノート・アーカイブCSV横断 キーワード該当行抽出機能

## 0. Antigravity-CLI 実装ガイドライン（前提・制約）
本ドキュメントは、VS Code上の **Antigravity-CLI** がコード生成・既存ファイル改修を行う際の直接的な実装仕様書である。実装時は以下のプロジェクト固有ルールを厳守すること。

1. **ビルド不要のCDN構成（さくらレンタルサーバー稼働前提）**
   * `npm` / `Webpack` / `Vite` 等のビルド工程は一切使用しない。
   * フロントエンドはブラウザ標準の ES Modules（`<script type="module">`）および CDN（Vue 2.x, Vuetify 2.x, Axios, Material Design Icons）を使用する。
2. **ディレクトリ階層と相対パス**
   * 本機能ページは `SourceCodes/pages/keywordLinesSearch/index.php` に配置されるため、`pages/index.php` より1階層深い。
   * 静的ファイル参照は `../../static/...`、APIエンドポイント参照は `../../server/api/...` を使用する。
3. **既存機能への影響最小化**
   * 既存ファイルへの変更は `SourceCodes/pages/index.php` のヘッダーアイコン追加（1箇所）のみとし、他の既存ファイル（`getCsvList.php`, `style.css` 等）は変更しない。
4. **文字コード・セキュリティ**
   * 全ファイル UTF-8（BOMなし）で保存する。
   * DB接続は既存 `server/db.php`（PDOプリペアドステートメント）を使用し、XSS対策としてHTMLハイライト描画時はエスケープ処理と安全に組み合わせる。

### 1.4 【新規】`SourceCodes/server/api/getKeywordLinesList.php`
* **目的**：選択されたソース（DB `ulinker_notes` および `storage/csv/ulinker_notes*.csv`）から、閲覧権限を満たし、かつ検索キーワードを含む行を持つレコードを `contents_id` 昇順で最大 `limit` 件まで抽出して返却する。

#### A. リクエスト受信・バリデーション仕様
* `session_start()` を実行。
* リクエストボディ（`php://input` の JSON デコード、または `$_POST`）から以下を取得する。
  * `token` (string)
  * `keyword` (string)
  * `sources` (array)
  * `limit` (int)
* **認証・入力チェック**：
  1. `!isset($_SESSION['session_string']) || $_SESSION['session_string'] === '' || !isset($_SESSION['owner_id'])` → HTTP `401`、`{"status": "unauthorized", "message": "ログインセッションが無効です。"}`
  2. `!isAlphanumeric16($token)` → HTTP `400`、`{"status": "error", "message": "不正なリクエストトークンです。"}`
  3. `trim($keyword) === ''` → HTTP `400`、`{"status": "error", "message": "検索キーワードを入力してください。"}`
  4. `!is_array($sources) || count($sources) < 1 || count($sources) > 4` → HTTP `400`、`{"status": "error", "message": "検索対象ソースは1件以上4件以内で指定してください。"}`
  5. `!in_array((int)$limit, [10, 50, 100, 500], true)` → デフォルト `50` に補正（またはエラー）。
* **キーワード正規化（サーバー側二重防御）**：
  * フロント側でも先頭1語抽出を行うが、API側でも念のため `preg_split('/[\s　]+/u', trim($keyword), 2)[0]` により**先頭の1ワードのみ**を確定キーワード `$targetKeyword` とする。

#### B. アンエスケープ関数仕様（`unescapeUlinkerText(string $text): string`）
PHP内で以下の順序で変換を実行する（順番が重要：`&amp;` を先に変換すると二重デコードになるため、独自エンティティ変換後に `htmlspecialchars_decode` を実行する）。
```php
function unescapeUlinkerText(string $text): string {
    $customMap = [
        '&nbsp;' => ' ',
        '&com;'  => ',',
        '&yen;'  => '\\',
        '&copy;' => '©',
    ];
    $text = str_replace(array_keys($customMap), array_values($customMap), $text);
    return htmlspecialchars_decode($text, ENT_QUOTES | ENT_HTML5);
}
```

#### C. 閲覧権限判定関数仕様（`canViewRecord(int $createdUserId, int $publicity, int $ownerId, int $isTeacher): bool`）
```php
function canViewRecord(int $createdUserId, int $publicity, int $ownerId, int $isTeacher): bool {
    if ($createdUserId === $ownerId) {
        return true;
    }
    if ($publicity === 1) { // 1: 公開
        return true;
    }
    if ($isTeacher === 1 && $publicity === 2) { // 2: 講師にのみ公開
        return true;
    }
    return false;
}
```

#### D. 行分割・キーワード判定仕様（`extractMatchedLines(string $noteText, string $keyword): array`）
```php
function extractMatchedLines(string $noteText, string $keyword): array {
    // CRLF / CR / LF を統一的に分割（各行の行頭・行末スペース/タブはトリムしない）
    $lines = preg_split('/\r\n|\r|\n/', $noteText);
    $matched = [];
    foreach ($lines as $line) {
        if ($line !== '' && mb_stripos($line, $keyword, 0, 'UTF-8') !== false) {
            $matched[] = $line;
        }
    }
    return $matched;
}
```

#### E. ソース別走査・上限打ち切りフロー
* 結果格納配列 `$results = []`（全体通算件数 `count($results)` が `$limit` に達したら即座に全ループ終了）。
* `$sources` の配列順に走査する（画面上でDBが先頭にあるため、通常 DB → CSV の順で処理される）。

1. **`$source === 'ulinker_notes'`（DB検索）の場合**：
   * SQL：`SELECT contents_id, title, note, publicity, created_user_id FROM ulinker_notes ORDER BY contents_id ASC`
   * 1行ずつフェッチし：
     * `canViewRecord((int)$row['created_user_id'], (int)$row['publicity'], $ownerId, $isTeacher)` が `false` なら `continue`。
     * `$plainTitle = unescapeUlinkerText((string)$row['title']);`
     * `$plainNote  = unescapeUlinkerText((string)$row['note']);`
     * `$matchedLines = extractMatchedLines($plainNote, $targetKeyword);`
     * `count($matchedLines) > 0` であれば `$results[]` に追加：
       ```php
       $results[] = [
           'recordKey'    => 'DB_' . (int)$row['contents_id'],
           'contentsId'   => (int)$row['contents_id'],
           'sourceType'   => 'DB',
           'sourceName'   => 'ulinker_notes',
           'title'        => $plainTitle,
           'matchedLines' => $matchedLines,
       ];
       ```
     * `if (count($results) >= $limit) break;`

2. **`$source` が `ulinker_notes*.csv`（CSV検索）の場合**：
   * **パストラバーサル防止チェック**：
     * `basename($source) === $source` であること。
     * `preg_match('/^ulinker_notes[a-zA-Z0-9_\-]*\.csv$/', $source) === 1` であること。
     * `file_exists('../../storage/csv/' . $source)` が `true` であること。
   * CSV読み込みと `contents_id` 昇順ソート：
     * `SplFileObject` または `fgetcsv` で全行読み込み（ヘッダー行がある場合は `is_numeric($row[0])` でスキップ判定）。
     * 各行の列マッピング（既存 `functions.php` 準拠）：
       * `$contentsId = (int)$row[0]`
       * `$rawTitle = (string)($row[1] ?? '')`
       * `$rawNote = (string)($row[4] ?? '')`
       * `$publicity = (int)($row[5] ?? 0)`
       * `$createdUserId = (int)($row[10] ?? 0)`
     * 読み込んだ有効行配列を `$contentsId` の昇順（`usort` で `$a['contentsId'] <=> $b['contentsId']`）にソートする。
   * ソート済み配列を走査し、DB検索と同一の `canViewRecord` → `unescapeUlinkerText` → `extractMatchedLines` を実行し、ヒットしたら以下を追加（`count($results) >= $limit` で即 `break`）：
     ```php
     $results[] = [
         'recordKey'    => 'CSV_' . $source . '_' . $contentsId,
         'contentsId'   => $contentsId,
         'sourceType'   => 'CSV',
         'sourceName'   => $source,
         'title'        => $plainTitle,
         'matchedLines' => $matchedLines,
     ];
     ```

3. **レスポンス返却**：
   ```php
   header('Content-Type: application/json; charset=utf-8');
   echo json_encode([
       'status'          => 'success',
       'keyword'         => $targetKeyword,
       'totalHitRecords' => count($results),
       'records'         => $results,
   ], JSON_UNESCAPED_UNICODE);
   ```

#### B. ライフサイクル（`mounted()`）
* `../../server/api/getCsvList.php` へリクエストを送信し、取得したCSVファイル名リストから `fileName.startsWith('ulinker_notes')` に一致するものを抽出。
* `availableSources` を以下の構造で構築する：
  ```javascript

    // 以降、取得した CSV ファイルごとに { value: fileName, label: fileName, type: 'CSV' }
  ```

#### C. 算出プロパティ（`computed`）
1. **`sortedConfirmedRecords`**：
   `confirmedRecords` のシャローコピーに対し、`sortOrder` に応じてリアルタイムにソートした配列を返す。
   * `'created_asc'`（作成-昇順）：`a.contentsId - b.contentsId`（同一ID時は元のインデックス順維持）
   * `'created_desc'`（作成-降順）：`b.contentsId - a.contentsId`
   * `'title_asc'`（タイトル順）：`a.title.localeCompare(b.title, 'ja')`
2. **`plainOutputText`**：
   `sortedConfirmedRecords` と `confirmedKeyword` をもとに、**案Bフォーマット**の純粋なプレーンテキストを生成する（コピー・TXTダウンロードで共通利用）。
   ```javascript
   const lines = [`検索キーワード: ${this.confirmedKeyword}`, ''];
   this.sortedConfirmedRecords.forEach((rec, idx) => {
     lines.push(`■ ${rec.title}（出典: ${rec.sourceName}）`);
     rec.matchedLines.forEach((line) => {
       lines.push(`・${line}`);
     });
     if (idx < this.sortedConfirmedRecords.length - 1) {
       lines.push('');
     }
   });
   return lines.join('\n');
   ```

#### D. 主要メソッド（`methods`）仕様
1. **`extractFirstKeyword(rawText)`**：
   * `const trimmed = (rawText || '').trim();`
   * `if (!trimmed) return '';`
   * `return trimmed.split(/[\s\u3000]+/)[0];`（半角・全角スペース区切りの先頭1語のみ返す）
2. **`executeSearch()`（Step 1「検索」ボタン）**：
   * `errorMessage = ''` にリセット。
   * `const kw = this.extractFirstKeyword(this.inputKeyword);`
   * バリデーション：
     * `!kw` → `errorMessage = '検索キーワードを入力してください。'` で中断。
     * `this.selectedSources.length < 1 || this.selectedSources.length > 4` → `errorMessage = '検索対象ソースは1件以上4件以内で選択してください。'` で中断。
   * `isSearching = true` にし、`../../server/api/getKeywordLinesList.php` へ `POST`（`token`, `keyword: kw`, `sources: this.selectedSources`, `limit: this.limitCount`）。
   * 正常レスポンス時：
     * `this.confirmedKeyword = res.data.keyword;`
     * `this.hitRecords = res.data.records || [];`
     * `this.checkedRecordKeys = [];`（**必ず全未チェック状態にする**）
     * `this.hasSearched = true;`
     * `this.showStep3 = false;`（再検索時は Step 3 と並び替えバーを一旦閉じる）
     * `this.confirmedRecords = [];`
3. **`resetAll()`（Step 1「リセット」ボタン）**：
   * `this.inputKeyword = '';`
   * `this.confirmedKeyword = '';`
   * `this.selectedSources = [];`
   * `this.limitCount = 10;`
   * `this.errorMessage = '';`
   * `this.hasSearched = false;`
   * `this.hitRecords = [];`
   * `this.checkedRecordKeys = [];`
   * `this.confirmedRecords = [];`
   * `this.showStep3 = false;`
   * `this.sortOrder = 'created_asc';`
4. **`selectAllRecords()` / `deselectAllRecords()`（Step 2 補助ボタン）**：
   * 全選択：`this.checkedRecordKeys = this.hitRecords.map(r => r.recordKey);`
   * 全解除：`this.checkedRecordKeys = [];`
5. **`showMatchedLines()`（Step 2「キーワードを含む行の一覧を表示」ボタン）**：
   * `if (this.checkedRecordKeys.length === 0) return;`
   * チェックされた `recordKey` に一致するレコードを `this.hitRecords` から抽出（`contentsId` 昇順を維持）し、`this.confirmedRecords` へ格納（上書き更新）。
   * `this.showStep3 = true;`
   * **最重要仕様**：`this.checkedRecordKeys = [];`（**表示確定と同時に Step 2 のチェックボックスをすべて未チェック状態へリセットする**）。
6. **`highlightLineHtml(lineText)`（画面描画用ハイライト＆XSS防御）**：
   * まず `lineText` をHTMLエスケープ（`&` → `&amp;`, `<` → `&lt;`, `>` → `&gt;`, `"` → `&quot;`, `'` → `&#39;`）する。
   * 同様に `this.confirmedKeyword` もHTMLエスケープし、正規表現特殊文字をエスケープした上で大文字・小文字を区別しないグローバル置換（`new RegExp('(' + escapedRegexKw + ')', 'gi')`）を行い、`<mark class="hl-keyword">$1</mark>` で囲む。
   * **注意**：PHP側で既にアンエスケープ済みのため、ここでは決して `commonFunctions.unescapeText()` を呼び出さないこと。
7. **`copyResultText()`（「表示テキストをコピー」ボタン）**：
   * `navigator.clipboard.writeText(this.plainOutputText)` を実行し、`copyFeedbackMessage = 'クリップボードにコピーしました！'` を3秒間表示する。
8. **`downloadResultTxt()`（「表示テキストをダウンロード」ボタン）**：
   * 現在日時から `yyyyMMdd_HHmmss` を生成し、ファイル名 `keyword_searched_${timestamp}.txt` を組み立てる。
   * `new Blob([this.plainOutputText], { type: 'text/plain;charset=utf-8' })` を生成し、一時的な `<a download="...">` 要素クリックによりダウンロードを実行する。
